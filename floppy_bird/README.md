## Game Features

- Collect stars to fill your shield meter
- Collect hearts to gain extra lives
- Activate shield to become invulnerable temporarily
- Choose difficulty level (Easy, Medium, Hard) for different numbers of lives
- The game saves your high score using local storage

## Code Structure

The game follows OOP principles with these main classes:

- `Game`: Main game controller
- `Bird`: Player character with movement and collision
- `Pipe`: Obstacle generation and management
- `PowerUp`: Collectible items (hearts and stars)
- `ParticleSystem`: Visual effects
- `Background`: Parallax scrolling background
