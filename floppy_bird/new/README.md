# Floppy Bird

## Features

- **Multiple Lives**: Choose difficulty level to determine starting lives
- **Power-ups**: Collect hearts for extra lives and stars for visual effects
- ⭐: Energy
- ❤️: Extra life

## Controls

- **Space / Up Arrow**: Fly up
- **Left / Right Arrow**: Move horizontally
- **Enter**: Restart game after game over

## Difficulty Levels

- **Easy**: Start with 7 lives
- **Medium**: Start with 5 lives
- **Hard**: Start with 3 lives
